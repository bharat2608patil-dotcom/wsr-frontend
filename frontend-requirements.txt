The backend APIs use a common response structure.

For example, a successful create API returns:

 Response Handling Requirements

The frontend must correctly understand that the actual API payload is wrapped inside:

javascript
response.data


and the backend's business data is inside:

javascript
response.data.data


For example:

javascript
const response = await api.get("/teams");

const backendResponse = response.data;

const teams = backendResponse.data.content;


Do NOT incorrectly assume that:

javascript
response.data.content


is the backend list.

Create reusable response handling utilities/types so this logic is not duplicated throughout the application.

javascript

because the backend uses the wrapper:

text
